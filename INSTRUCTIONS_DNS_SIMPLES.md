## 📝 OÙ LES COLLER ?

### 1. Connectez-vous à votre compte de gestion de domaine
Là où vous avez acheté **talentproof.africa**

### 2. Trouvez la section "Nameservers"
Peut aussi s'appeler :
- DNS Servers
- Serveurs de noms
- Name Server Settings

### 3. Changez le mode
Sélectionnez :
- "Custom Nameservers" ou
- "Use custom nameservers"

### 4. Collez les 2 valeurs
```
Nameserver 1: ns1.vercel-dns.com
Nameserver 2: ns2.vercel-dns.com
```

### 5. Sauvegardez
Cliquez "Save" ou "Enregistrer"
